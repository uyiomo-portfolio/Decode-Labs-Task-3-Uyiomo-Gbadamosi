# SQL Basics - Data Analysis

## Project Overview

This project was completed as part of my SQL learning and data analytics training. The objective was to build a strong foundation in SQL by working with data and applying fundamental SQL commands to extract, filter, summarize an organize information.

The analysis focused on using SQL to answer business related questions and generate meaningful insights from the dataset.

## objectives

The main objectives of the task were to:

▪️Retrieve data using SELECT

▪️Filter records using WHERE

▪️Count records using COUNT ()

▪️Perform calculations using aggregate functions

▪️Group data using GROUP BY

▪️Sort results using ORDER BY

▪️Understanding how SQL can be used to analyze datasets and support data driven decisions

## SQL concepts applied

### 1. SELECT 

Used SELECT to retrieve specific column and records from the dataset.

### 2. WHERE

Used WHERE to filter data based on specific conditions and focus on relevant records.

### 3. COUNT()

Used COUNT () to determine the number of records and measures the volume of data.

### 4. Aggregate Functions

Applied aggregate functions such as:

COUNT() - count records
SUM() - calculate totals
AVG() - calculates averages
MIN() - identifies the minimum value
MAX() - identifies the maximum value

### 5. GROUP BY

Used GROUP BY to organize records into categories and perform aggregate calculations for each group.

### 6. ORDER BY

Used ORDER BY to sort query results in ascending or descending order, making the results easier to interpret.
